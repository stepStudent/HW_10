**Тема:** Створення інтерактивного вебсайту за допомогою штучного інтелекту.  
**Мета:** Закріпити роботу з Bootstrap 5, змінними, арифметичними операторами та умовами `if/else` у JavaScript.

## 🎯 Виконання вимог завдання

1. **HTML5 та Bootstrap 5:**
   - Підключено Bootstrap 5.3 (CSS та JS Bundle), Bootstrap Icons.
   - Використано сітку `container`, `row`, `col-lg-8`, адаптивні класи утиліт.
2. **Інформація про подію:**
   - Заголовок: Рок-концерт гурту «Thunderstorm».
   - Опис: Світовий тур «Вогняний Шторм», деталі програми.
   - Дата: 25 травня 2025, 19:00.
   - Місце проведення: м. Київ, Клуб «Atlas».
3. **Форма реєстрації:**
   - Поле **Ім'я** (`#userName`).
   - Поле **Email** (`#userEmail`).
   - Поле **Кількість учасників** (`#participantsCount`).
   - Кнопка **«Зареєструватися»** (`#submitBtn`).
4. **JavaScript логіка:**
   - **Змінні та константи:** `const TICKET_PRICE = 650;`, `let userName`, `let userEmail`, `let participantsCount`, `let totalPrice`.
   - **Арифметичні оператори:** розрахунок загальної суми квитків (`participantsCount * TICKET_PRICE`).
   - **Умови `if/else`:**
     - Перевірка, чи не порожнє поле `userName`.
     - Перевірка, чи не порожнє поле `userEmail` та чи валідний формат email.
     - Перевірка, чи `participantsCount > 0`.
   - **Виведення результату:**
     - При успішній перевірці виводиться: `«Реєстрація успішна!»` разом із деталями бронювання та сумою.
     - При помилці виводиться стилізоване повідомлення про помилку з вказівкою, що саме слід виправити.
